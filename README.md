# Andalusi - Spanish Learning Web App 🇪🇸

A modern, sleek, and responsive web application designed for learning Spanish, featuring a gorgeous dark mode interface (Teal & Charcoal theme), interactive flashcards, and an idiom library tailored for beginners.

🔗 **[Live Demo - Try Andalusi Here](https://andalusi-three.vercel.app/)**

## 🚀 Features
- **Interactive Flashcards:** Dynamic card system to memorize vocabulary and phrases efficiently.
- **Idiom & Phrase Library:** Curated Spanish expressions with translations and usage context (English ↔ Arabic support).
- **Modern Dark Mode UI:** Built with a professional Teal and Charcoal aesthetic for a distraction-free learning experience.
- **Fully Responsive:** Optimized for seamless usage across desktop and mobile devices.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 / Tailwind CSS, JavaScript
- **Build Tool:** Vite
- **Icons & Styling:** Custom CSS architecture with clean component structures.

## 💾 Backend & Database
- **Database & Auth:** Powered by Supabase for secure user authentication and managing interactive flashcards data persistence.
